How CyberTrace Detects Threat Anomalies
CyberTrace combines deterministic cybersecurity heuristics with Scikit-learn machine learning. Each event accumulates risk points based on foreign network origins, authentication anomalies, sensitive file access, and payload volumes.

⚖️ Anomaly Risk Scoring Formula Matrix

Unusual Foreign IP +20 Points
Multiple Failed Logins +20 Points
Sensitive File Access +20 Points
Large Data Transfer +15 Points
Permission Change +10 Points
Compounding Bonus +7 Points
