💡 How CyberTrace Works (8-Step Architecture)

Interactive pipeline breakdown explaining the full data and forensic intelligence lifecycle
⏱️ Open Time Machine
💡
System Pipeline Navigation
Click on any stage below to inspect how the frontend, Python backend, Pandas cleaning, AI anomaly scoring, Supabase database, and ReportLab PDF generator interact.
STAGE 01

📤 Upload Security Logs

Investigators upload CSV log files containing user activity, IP addresses, and file transactions.

What happens? The browser reads the CSV file and uses JavaScript fetch() to transmit it to Python.

Why do we need it? Digital investigations begin by gathering system and security logs from firewalls, operating systems, and authentication servers.

Which Python file handles it? server.py & backend/events.py

Which Supabase table is involved? Ingestion stage before database write.

STAGE 02

🧹 Clean & Preprocess Data

Python Pandas standardizes columns, removes duplicate records, and fills missing values.

What happens? Pandas converts the raw text into a clean Python DataFrame, strips accidental spaces, and fills missing fields with safe defaults.

Why do we need it? Real-world logs are often messy. Cleaning ensures our anomaly math and database queries run without crashing.

Which Python file handles it? ai/preprocessing.py

Which Supabase table is involved? Stored into security_events.

STAGE 03

⚠️ Find Unusual Activity & Score Risk

Rule-based detection checks for foreign IPs, brute force logins, sensitive files, and data exfiltration.

What happens? Every event is evaluated against cybersecurity rules (e.g. Unusual IP +20, Sensitive File +20) to compute a score from 0 to 100.

Why do we need it? Security analysts cannot review millions of logs manually. Risk scoring highlights the exact critical threats instantly.

Which Python file handles it? ai/anomaly_detection.py

Which Supabase table is involved? security_events (columns: risk_score, severity, reason, is_anomaly).

STAGE 04

🔗 Connect Related Events (Correlation)

Groups isolated events by User, Device, IP, and Time into coordinated Incident cases.

What happens? Related suspicious events are linked together into an incident record (e.g. INC-001) tracking the multi-stage attack lifecycle.

Why do we need it? A cyber attack consists of multiple steps (access ➔ discovery ➔ exfiltration ➔ persistence). Correlation connects the dots.

Which Python file handles it? backend/correlation.py

Which Supabase table is involved? incidents.

STAGE 05

⏱️ Create Forensic Incident Timeline

Reconstructs the chronological event sequence for the Digital Forensics Time Machine.

What happens? Events are sorted by time with state markers, allowing investigators to step forward, pause, and jump directly to the first anomaly.

Why do we need it? Understanding WHEN each event happened is the foundation of digital forensics and incident response.

Which Python file handles it? backend/timeline.py

Which Supabase table is involved? security_events & incidents.

STAGE 06

🌐 Show Evidence Relationships

Generates relationship links (User ➔ Device ➔ IP ➔ File ➔ Payload Transfer).

What happens? Builds a graph of forensic assets showing first-seen and last-seen timestamps and linked risk scores.

Why do we need it? Demonstrates legal chain-of-custody and clear asset relationships for cybersecurity investigations.

Which Python file handles it? backend/evidence.py

Which Supabase table is involved? evidence.

STAGE 07

🤖 AI Forensic Investigation

Answers natural language questions strictly grounded in actual database log records.

What happens? The investigator asks "What happened?" or "What was the first suspicious event?" and Python answers using real database facts.

Why do we need it? Accelerates decision-making by summarizing complex forensic evidence in plain English without hallucinating.

Which Python file handles it? backend/investigator.py

Which Supabase table is involved? Queries all tables.

STAGE 08

📄 Generate Official Incident Report

Synthesizes findings into a professional audit report and generates a downloadable PDF.

What happens? CyberTrace formats an executive dossier and calls Python ReportLab to produce a publication-quality PDF.

Why do we need it? Critical for security leadership, legal compliance, and post-incident remediation audits.

Which Python file handles it? backend/report.py

Which Supabase table is involved? investigation_reports.
